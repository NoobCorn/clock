Paper

Designing for a Calmer Start

This site is a paper-app: an interactive clock and productivity tool paired with the research behind its design. The interface itself is the experiment — read on to see the thinking, then explore the clock, timer, and tasks to see it in practice.

Research Question
How can the design of a productivity tool help users feel less stressed when starting a task?

Why This Matters

Many productivity apps overload users with notifications, long task lists, streaks, deadlines, and visual clutter. These features are usually meant to motivate, but they can unintentionally increase stress instead of helping people begin. A screen full of red badges and overdue reminders can make starting a task feel heavier than the task itself.

This project explores whether a calmer interface — one that leads with time and presence rather than pressure — can lower the barrier to starting work.

Observation

Many productivity apps display overdue reminders, badges, notifications, and crowded task lists before users even begin working. The first thing a person sees when opening the app is often a signal that they are already behind.

Interpretation

A simpler interface that focuses on the present moment, time awareness, and optional productivity tools may reduce the mental effort required to begin working. If the default view is calm, any additional structure — like a task list or timer — becomes something the user opts into, rather than something imposed on them.

Design Decisions

Each choice in this clock supports the research question above.

Large Centered Clock

Gives the eye one calm focal point, anchoring the user in the present moment rather than a list of obligations.

Minimal Interface

Only the time is shown by default, reducing visual clutter and the sense of being overwhelmed on arrival.

Hidden Settings

Controls fade away until needed, keeping the screen quiet and putting the user in charge of complexity.

Optional Focus Mode

The timer is available but never forced, so structure is something the user chooses rather than something imposed.

Optional Ambient Sounds

Gentle, non-jarring alarm tones support focus without the harshness typical of default alarms.

Dynamic Backgrounds

Soft gradients and themes let the environment feel personal and pleasant rather than clinical.

User Customization

Fonts, themes, and clock styles are adjustable, giving users a sense of ownership over their space.

No Unnecessary Notifications

The app never interrupts unprompted, avoiding the anxiety that comes with constant pings and alerts.

Limitation

This project has only been tested informally, largely through personal use and observation. Different users may respond differently to a minimal interface — some may find it calming, while others may prefer more visible structure and reminders. Broader, more rigorous testing is needed to draw firm conclusions.

Next Steps

  • Conduct structured user testing with a wider group of participants.
  • Compare this interface against traditional, notification-heavy to-do apps.
  • Measure whether users begin tasks more quickly with a calmer starting screen.
  • Measure perceived stress before and after using the app, using a simple self-report scale.

Reflection

The goal of this project was never simply to tell time. It was to create an environment that encourages users to begin working calmly — where the interface gets out of the way, and starting a task feels like a small, quiet decision rather than a confrontation with everything left undone.
